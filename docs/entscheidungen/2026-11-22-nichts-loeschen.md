# Nichts löschen

Datum: 2026-11-22
Status: gilt

## Entscheidung
Weder Oberfläche noch API noch MCP können Dokumente löschen. Jede Änderung landet im `protokoll`.

## Warum
Claude soll nur einordnen. Für die SOMA-Instanz gelten Aufbewahrungsfristen nach GoBD, dort darf ohnehin nichts vor Fristablauf verschwinden.

## Folgen
Ein Löschen, falls es je gebraucht wird, kommt als eigene Entscheidung mit Prüfung der Aufbewahrungsfrist je Bereich.
